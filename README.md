# 🏮 달빛 운세 · 산사 마당 (3D 캐릭터 미리보기)

**바로 열기 → https://sinseon17.github.io/dalbit-unse-3d/**

고요한 달빛 사찰 마당에서 귀여운 남녀 캐릭터가 걷는 **3D 캐릭터 미리보기**입니다.
'달빛 운세' 서비스의 분위기와 캐릭터 애니메이션을 먼저 확인하기 위한 프로토타입입니다.

## 미리보기에서 할 수 있는 것
- **남자 / 여자 / 둘 함께** 전환 (상단 버튼)
- **바닥 클릭·터치** → 그 자리까지 걸어가기 (발밑에 달빛 링이 번짐)
- **자동 산책** → 돌길을 따라 알아서 거닐기
- **모바일 가상 조이스틱** / **PC WASD·방향키**로 직접 걷기
- **드래그(모바일 1손가락) · 휠/핀치**로 시점 회전·확대 (R 키로 시점 초기화)
- 캐릭터가 가만히 있으면 **고개 끄덕임**과 **합장** 모션
- **오늘의 달빛 운세** → 12띠 중 선택해 한 줄 운세 카드 뽑기 (버튼 1개)

## 구성
- 사찰 마당: 기와지붕 법당(달빛암), 계단, 돌길, 석탑, 석등, 소원 연등 줄, 소나무, 반딧불, 보름달과 별
- 캐릭터: 프리미티브로 만든 SD/치비 스타일 3D 모델 2종 (남자·여자), 절차적 걷기·끄덕임·합장 애니메이션
- 외부 라이브러리는 `vendor/three.module.js`(Three.js r160) 한 개뿐 — CDN 없이 동작
- 모바일 세로 화면에서는 화각과 카메라 거리를 자동으로 넓혀 마당이 더 보이게 함
- 카메라가 석등·석탑·법당을 뚫지 않도록 간단한 충돌 처리

## 실행
정적 파일만으로 동작합니다. GitHub Pages 주소로 바로 열거나, 로컬에서는 아무 정적 서버로 열면 됩니다.

```
python3 -m http.server 8000   # http://localhost:8000
```

## 파일
- `index.html` — 화면·UI·운세 카드 마크업과 스타일
- `app.js` — Three.js 씬, 캐릭터 모델·애니메이션, 이동·카메라, 운세 데이터
- `vendor/three.module.js` — Three.js r160 (MIT)
