# 🏮 달빛 운세 · 산사 마당 (3D 미리보기)

고요한 달빛 사찰 마당에서 귀여운 남녀 캐릭터가 걷는 **3D 캐릭터 미리보기**입니다.
달빛 운세 서비스의 분위기와 캐릭터 애니메이션을 먼저 확인하기 위한 프로토타입입니다.

## 미리보기에서 할 수 있는 것
- **남자 / 여자 / 둘 함께** 전환 (상단 버튼)
- **바닥 클릭·터치** → 그 자리까지 걸어가기 (발밑에 달빛 링이 번짐)
- **자동 산책** → 돌길을 따라 알아서 거닐기
- **모바일 가상 조이스틱** / **PC WASD·방향키**로 직접 걷기
- **드래그(모바일 1손가락) · 휠/핀치**로 시점 회전·확대
- 캐릭터가 가만히 있으면 **고개 끄덕임**과 **합장** 모션
- **오늘의 달빛 운세** → 12띠 중 선택해 한 줄 운세 카드 뽑기

## 구성
- 사찰 마당: 기와지붕 법당(달빛암), 계단, 돌길, 석탑, 석등, 소원 연등 줄, 소나무, 반딧불, 보름달과 별
- 캐릭터: 프리미티브로 만든 SD/치비 스타일 3D 모델 2종 (남자·여자), 절차적 걷기 애니메이션
- 외부 라이브러리는 `vendor/three.module.js`(Three.js r160) 한 개뿐 — CDN 없이 동작
